Ваши эксперименты

Шаг 1 из 4

Откуда взять фотографии

Рядом с каждым фото .jpg должна лежать маска .png с тем же именем: на ней закрашена ржавчина. Укажите три папки.

Для обучения 405 фото
Папка train. Здесь программа учится. Обычно это 70–80% всех снимков.
Для проверки в ходе обучения 101 фото
Папка valid. Эти снимки программа не видит при обучении, на них она сверяется после каждого прохода.
Для итоговой оценки необязательно 100 фото
Папка test. Используется один раз в конце. Можно оставить пустой.
Название эксперимента
