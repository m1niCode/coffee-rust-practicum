# Ржавчина на листьях: обучение и проверка модели

Приложение для агрономов: обучить нейросеть находить ржавчину на фото листьев кофе и применить её к новым снимкам.
Открывается в браузере, программировать не нужно. Прототип экранов лежит в `prototype/index.html`.

Сценарий лабораторного практикума «разметка → обучение» и подготовка учебных ПК — в [PRACTICUM.md](PRACTICUM.md).

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt    # для видеокарты NVIDIA поставьте torch по инструкции pytorch.org
python app.py
```

Браузер откроется сам (адрес http://127.0.0.1:8765). Для выбора папок кнопкой «Обзор…» нужен tkinter
(Linux: `sudo apt install python3-tk`). Интерфейс уже собран в `web/dist`, Node.js для запуска не нужен.

Данные лежат рядом с программой: `train/`, `valid/`, `test/` (фото `.jpg` и маски `.png` с тем же именем,
допустим суффикс `_mask`). Результаты обучения сохраняются в `OUT/<имя эксперимента>/`
(другая папка: переменная `RUST_OUT_DIR`).

## Структура

| Папка | Что внутри |
|---|---|
| `core/` | Вычислительное ядро: данные, обучение, применение модели, чтение экспериментов. Перенесено из `train_gui.py` и `infer_rust.py` без изменения алгоритмов |
| `server/` | FastAPI: API для интерфейса (`/api/...`), прогресс обучения по SSE, раздача `web/dist` |
| `web/` | Интерфейс: Vite, React, TypeScript (strict), zustand, ESLint. Структура FSD: `app, pages, widgets, features, entities, shared` |
| `prototype/` | Согласованный кликабельный макет (HTML) |
| `app.py` | Точка входа |
| `train_gui.py`, `infer_rust.py` | Старые Tkinter-программы, оставлены для сравнения |

## Разработка интерфейса

```bash
python app.py --no-browser         # сервер на :8765
cd web && npm install && npm run dev   # http://localhost:5173, /api проксируется на сервер
npm run lint && npm run build          # проверка и сборка в web/dist (папку dist нужно коммитить)
```

Правило FSD проверяет ESLint: нижние слои не импортируют верхние.

## Что осталось доделать

- Оценки «Отлично / Хорошо / Можно лучше» (`web/src/shared/lib/format.ts`) заданы по порогам 75% и 65% IoU. Пороги предложены для обсуждения.
- Время обучения на экране «Параметры» оценивается грубой формулой (`estimateMinutes`). Заменить реальным замером.
- В «Проверить фото» загружаются только фото без масок: сравнение с разметкой эксперта доступно для экспериментов (экран «Результаты»), но не для загруженных снимков.
- Результаты проверки не пишутся на диск, их можно скачать в CSV. Старый `infer_rust.py` сохранял маски и наложения в `OUT_test/`.
- Модели из статьи (YOLOv8, SAM2 в отдельной папке) в интерфейс не подключены.
- Проверено на macOS и Python 3.13. Windows и Linux не проверялись; обучение с видеокартой не проверялось.
